# Tests

Test domain disimpan di sini dan dijalankan dengan runner bawaan Node.js, tanpa dependency test tambahan.

- `npm test` menjalankan `node:test` pada Node.js 22.6 atau lebih baru.
- Model simulasi, aturan Cek, kontrak backend AI, penyamaran input, parser dan checklist konteks QRIS, filter panduan SOS, routing, dan HTML utama diuji dengan `node:test`.
- Decoder gambar dan perilaku responsif tetap perlu diperiksa manual pada Safari iPhone dan Chrome Android.
